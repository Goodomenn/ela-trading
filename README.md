# Ela Trading PLC

Global Commodity Export, Import & Hospitality Enterprise

A modern web application built with **React**, **Vite**, **Tailwind CSS**, and **Chart.js**, featuring an authentic vintage-editorial smokehouse aesthetic (inspired by LORO Asian Smokehouse & Bar).

## 🌾 Core Divisions

- **Agro-Commodity Export**: Specialty Arabica Coffee (Yirgacheffe & Sidamo G1), Humera Natural White Sesame Seeds, Tepi Turmeric & Spices, Rift Valley Pulses.
- **Import & Logistics**: Agricultural machinery, industrial food-grade packaging, fertilizers, multimodal freight forwarding.
- **Hospitality Subsidiaries**:
  - [Bricks Lounge](https://minnnn.vercel.app/) — Luxury nightlife, mixology & fine dining.
  - [Ela Catering Services](https://elacatering.com) — Diplomatic banqueting & institutional catering.

## 🛠️ Tech Stack

- **React 18**
- **Vite 6**
- **Tailwind CSS**
- **Chart.js** (Interactive Quality Radar Chart)
- **Google Fonts**: Fraunces, Courier Prime, Space Mono, Plus Jakarta Sans

## 🚀 Getting Started

### Install Dependencies
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
